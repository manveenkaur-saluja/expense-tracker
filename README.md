
# Expense Tracker V3

A Python project built to record, manage, analyse, and visualize personal expenses using CSV storage and Python data libraries.

## Features

- **Add Expenses:** Record an expense category and amount with automatic date and time.
- **View All Expenses:** Display recorded expenses and total spending.
- **Delete Expenses:** Remove an expense by its ID.
- **Update Expenses:** Modify an expense's category, amount, or date.
- **Category Summary:** Calculate total spending for each category.
- **Search and Filter:** Find expenses by category.
- **Monthly Reports:** Calculate total spending for a selected month.
- **Data Visualization:** Generate pie charts, horizontal bar charts, and monthly spending trend charts.

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV file handling
- Object-oriented programming
- Exception handling

## Installation

Make sure Python is installed.

Install the required libraries:

```bash
pip install pandas matplotlib
```

Clone the repository:

```bash
git clone https://github.com/manveenkaur-saluja/expense-tracker.git
cd expense-tracker
```

## Data Storage

Expenses are stored in a CSV file containing:

| Field | Description |
|---|---|
| ID | Expense identifier |
| Category | Expense category |
| Amount | Money spent |
| Date | Date of the expense |
| Time | Time the expense was recorded |

## Visualizations

The application supports:

- **Pie chart:** Shows the distribution of spending across categories.
- **Bar chart:** Compares spending across categories.
- **Line chart:** Shows monthly spending trends.
